# Yin-Yang Spinner

![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-F7DF1E?logo=javascript&logoColor=000)

A simple JavaScript web app that draws animated spinner designs on a canvas. Click the **Spin** button to rotate the selected spinner clockwise, or use the hamburger menu to switch between the Yin-Yang spinner and a red-and-white spiral. Adjust the RPM (revolutions per minute) with the slider (default: 11 RPM).

## Features
- Draws multiple spinner styles on an HTML5 canvas
- Hamburger menu with a flyout spinner picker
- Red-and-white spiral spinner option
- Spin button toggles rotation
- RPM slider (11–1350, default 11)

## Getting Started

1. **Install dependencies:**
   This project uses [serve](https://www.npmjs.com/package/serve) for local development. Install it globally or run with npx.

   ```bash
   npm install
   ```

2. **Start the app:**
   ```bash
   npm start
   ```
   Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure
- `index.html` — Main HTML file
- `style.css` — App styling
- `main.js` — Drawing and animation logic
